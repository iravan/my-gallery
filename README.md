# My Gallery

A 3D gallery in the browser for showing artworks: two round, skylit rooms joined by a corridor. Live at https://iravan.github.io/my-gallery/.

**Artworks:** put images in [`web/public/artworks/`](web/public/artworks/) and describe each one in `artworks.json`
(title, artist, year, medium, description, and which of the 18 hanging spots it takes). Click an artwork in the room to read its
description. Field reference: [`web/public/artworks/README.md`](web/public/artworks/README.md).

## Features

- **Artworks** — framed and spotlit in the gallery's hanging spots from a folder + JSON config; click one for its description
- **Gallery** — "Richard's Art Gallery – Audio Tour" with its baked lighting, as a React component
  (`web/components/room/GalleryModel.tsx`, generated by gltfjsx) over an optimised model (`web/public/gallery/gallery.glb`);
  hanging spots and walkable floor plan in `web/lib/gallery.ts`
- **Walk around** — drag to look, WASD / touch stick to move; walls and tables block you
- **Showcase** — photo mode, HUD-free showcase mode

Forked from My Room (a vinyl bedroom); the bedroom, vinyl features and room editor were removed.

## Quick start

```sh
cd web
bun install
bun run dev     # http://localhost:3000
```

Requires **Bun 1.4**. Useful scripts:

```sh
bun run build
bun run test    # Vitest: artworks config, floor plan
bun run check   # headless Chrome: screenshots, drag artifact scan, FPS
```

More notes live in [`web/README.md`](web/README.md).

## Gallery model

"[Richard's Art Gallery – Audio Tour](https://sketchfab.com/3d-models/richards-art-gallery-audio-tour-0e3e19faa6474fd5974e6a7ed1b221d8)"
by [shinymagic](https://sketchfab.com/shinymagic), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Changes: hidden helper meshes and the ground disc removed, textures converted to WebP (2048 px for walls and floor,
1024 px for the rest), animation resampled (58 MB → 14.5 MB), drawn unlit. The original pictures stay; each one is hidden
while one of your artworks hangs in its spot.

To redo it from the source file: with gltf-transform remove `XXX_DO_NOT_RENDER` and `Circle001`, prune/dedup/weld/resample,
WebP textures (no meshopt: its quantisation makes gltfjsx place meshes at the wrong scale), then
`npx gltfjsx@6.5.3 gallery.glb -t -p 6` (6 decimals: the root scale is 0.0012077, and the default 3 rounds it to 0.001) and re-apply the edits noted at the top of `GalleryModel.tsx`.
